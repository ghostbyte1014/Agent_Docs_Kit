# Security policy

## Supported versions

Security fixes are provided for the current npm release. Upgrade with `npm install --global @ghostbyte/agent-docs-kit@latest` or use the version-pinned `npx` form.

## Reporting a vulnerability

Do not open a public issue for an exploitable vulnerability or include secrets, personal data, or live-target details in a report. Use GitHub private vulnerability reporting for `ghostbyte1014/Agent_Docs_Kit`. Include the affected version, impact, reproduction conditions, and a safe proof of concept.

The project’s worksheets are review aids. They do not automatically scan targets, prove compliance, or replace professional security testing.
