Documentation & Session Governance for AI Coding Agents

A transparent, structured documentation framework and change-auditing system for human developers collaborating with AI coding agents.

v3.0 – v3.2

Session Gate

Mandatory sequential startup questions (Freeze first, Records second) on every fresh session. Strict read-only mode until confirmed.

v1.2

Change Freeze

Enforces per-file developer authorization. AI agents must check against documented scope before proposing code edits.

v2.0 – v2.1

Audit Integrity

Commit-scoped change records in UTC+8 logging modified files, AI model, author approval, and reproducible verification steps.

v2.2

Git Enforcement

Pre-commit Git hooks and audit scripts in Node.js and Python that fail closed if unrecorded modifications are staged.
