Privacy notice

Effective: October 15, 2026

This notice explains the limited data behavior of the Agent Docs & Quality Kit website and CLI. The project is an open-source tool, not an account-based service.

Website data

This static website does not include project-operated analytics, advertising, forms, accounts, or tracking cookies. It stores one preference in your browser's local storage under agent-docs-command-mode so command examples can remember whether you selected npx or a global installation. That preference stays in your browser and can be removed through your browser's site-data controls.

The canonical website is served as static assets through Cloudflare Workers at agent-docs-kit.ghostbyte1014.workers.dev. The repository retains a workflow that can publish the same assets through GitHub Pages as an optional mirror, but that mirror may be unavailable. Cloudflare can process requests to the canonical site, and GitHub can process requests if you visit a GitHub-hosted project page or mirror. Each provider acts under its own policies. This project does not control, and does not make promises about, either provider's infrastructure logging.

CLI and project files

The Agent Docs CLI has no project telemetry service and does not send your documentation, worksheets, source code, or audit results to this project. Explicit commands read or write files in the project directory you select. The package does not start a background service or run an active network security scan.

Downloading the package with npm or npx communicates with the npm registry. npm documents that registry requests can include technical and request data such as IP address, package name and version, Node.js/npm versions, operating system, and user-agent information. That processing is controlled by npm, not by this project.

AI tools and external links

If you use the optional skill with an AI coding agent, data handling is governed by the agent provider, your account or organization settings, and the permissions you grant. Review those terms before sharing source code, credentials, personal data, or security evidence. Links from this site can take you to third-party services with their own policies.

Official third-party policies

  • GitHub Pages and data collection
  • GitHub Privacy Statement
  • npm Privacy Policy

Questions and changes

For questions about this project's behavior, use the repository's public issue tracker without including secrets or personal data. Report security vulnerabilities through GitHub private vulnerability reporting. This notice may change when the website, CLI, hosting, or data behavior changes; the effective date above will be updated.
